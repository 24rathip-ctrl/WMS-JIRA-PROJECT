Project Information & Architecture (Viva Quick Reference)

Frontend: HTML5, CSS3, Vanilla JavaScript (Fetch API, zero frameworks)
Backend: Java Servlets (ProductServlet, InventoryServlet)
Data Layer: JDBC with PreparedStatement (SQL-injection safe)
Database: MySQL 8.4 (wms_db on port 3306)
Server: Apache Tomcat 9.0.97
Security: Server-side validation, XSS escaping, least-privilege DB user
